# Som Nath Pahari — Portfolio Website

A React + Vite + Tailwind CSS static portfolio site.

## Local development

```
npm install
npm run dev
```

## Production build

```
npm run build
```

This outputs a static site to the `dist/` folder — everything needed
to host on somnathpahari.com.np. No server or backend is required.

## Editing content

Nearly all text on the site (name, roles, experience, social links,
etc.) lives in `src/data/content.js`. Edit that file to update the
site without touching any layout code.
